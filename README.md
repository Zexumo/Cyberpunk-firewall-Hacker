# Nestle_Arasaka
Este programa simula um hacker tentando contornar o firewall de uma rede corporativa, com as seguintes regras implementadas:

- O jogador tem **3 tentativas** para acertar a senha
- Mesmo acertando a senha, o acesso depende da **RAM do deck** comparada à **força da senha**
- Entradas inválidas ou vazias são tratadas com **Null Safety** do Kotlin
- O sistema bloqueia e notifica a segurança ao esgotar as tentativas

para executar o programa, é necessário acessar o arquivo Main.kt
